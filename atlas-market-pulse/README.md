# Atlas Market Pulse (retired) — historical snapshot

**Atlas Market Pulse is a retired product.** Its live successor is **[Atlas Quakes](https://atlas.freedomcore.io/quakes/)**: source-dated company and protocol developments with the event date kept separate from the quote observation time.

The files in this folder (`atlas-market-pulse.json`, `schema.json`) are the **retained 2026-07-20 snapshot** as last published to this repository. They are preserved unchanged for historical citations and are not refreshed, restamped or relabelled.

- Canonical dataset page: [`/datasets/atlas-market-pulse/`](https://atlas.freedomcore.io/datasets/atlas-market-pulse/)
- Live successor: [`/quakes/`](https://atlas.freedomcore.io/quakes/)
